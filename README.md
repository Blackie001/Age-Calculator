# AgeCalculator 🧮 

A clean and user-friendly age calculator built using **HTML, CSS, and JavaScript**.  
It calculates a person’s exact age and also shows the number of days remaining until their next birthday.

Designed with a dull patterned background for a calm, modern UI experience.

---

## ✨ Features

- 📅 Calculates **exact age** (years, months, days)
- ⏳ Displays **days remaining until the next birthday**
- 🎨 Dull gradient background with a subtle CSS pattern
- ✅ Uses date inputs to prevent invalid entries
- 💡 Simple, readable, and extendable code structure

---

## 🛠️ Built With

- **HTML5** – Structure  
- **CSS3** – Styling, gradient & pattern background  
- **JavaScript (Vanilla)** – Date logic and calculations
